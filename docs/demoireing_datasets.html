Provenance notes

  • TIP-2018 counts cross-checked against the paper's per-class PSNR table (row sums match 118,448 / 11,851 exactly).
  • UHDM stats confirmed on the official project page (5,000 pairs; random 4,500 / 500 split; DJI OM 5 gimbal capture).
  • Papers with Code is defunct (redirects to Hugging Face), so challenge / leaderboard links are unavailable.
  • LCDMoire: official ETH links verified dead (404) in 2026-11; the full 10,200-pair copy exists only on a Baidu Pan mirror (verified listing: Training.zip 4.27 GB plus two validation zips; login required). The local copy in datasets/LCDMoire/ is a login-free community subset (3,160 JPEG pairs, 1024 × 1024).
  • Sources: arXiv native HTML, ar5iv, OpenAlex, DBLP (blocked), official project pages, GitHub issue threads (LCDMoire mirror discovery). Dataset binaries are not tracked in git (see .gitignore).
